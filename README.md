# G Saiteja — Creative Portfolio

A responsive dark/futuristic portfolio built with plain HTML, CSS and JavaScript.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace `YOUR_USERNAME` in the GitHub and LinkedIn links.
3. Put your actual resume PDF at `assets/resume.pdf`.
4. Add your Power BI dashboard image to `assets/` if desired and update the project card.
5. Replace/add project links.

## Free hosting — GitHub Pages
1. Create a public repository named `YOUR_USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `assets/`.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)`.
5. Open `https://YOUR_USERNAME.github.io`.

## Alternative — Vercel
Import this repository into Vercel and deploy. No build command is required.

## Local preview
Open `index.html` directly in a browser, or run a simple local server:
`python -m http.server 8000`
Then open `http://localhost:8000`.
